# Paper drafts

Machine-assisted drafts of the PEEK-Bench paper. **Not submitted, not peer reviewed, and not
edited by the first author yet.** Both formats render from a single Markdown source via
`render.py`, so the `.docx` and `.pdf` cannot drift apart.

| file | |
|---|---|
| **`PEEK-Bench-draft-v2.pdf` / `.docx`** | **current draft** — 35 pages, 13 tables, 6 figures, 54 references |
| `PEEK-Bench-draft-v2.md` | source of truth for both |
| `PEEK-Bench-draft.pdf` / `.docx` / `.md` | superseded first attempt, kept for comparison (see below) |
| `figures/*.png` | generated by matplotlib from the scored result JSONs |
| `refs.json` | the 54 references with verification provenance per entry |

## Why there are two drafts

The v1 pipeline had a bug: the merge prompt claimed to include seven independently drafted
sections and never interpolated them, so one agent wrote the whole paper from the facts table alone
and 61k characters of section drafts were discarded. The agent noticed and said so in its own
editor's notes. v2 is the same pipeline with the drafts actually attached — hence the scorer
material splitting into a design-space section and an evidence section, which v1 collapsed.

## Provenance of the numbers

Every figure in the drafts was compiled into a locked facts table straight from the scored result
JSONs and workbooks before drafting began, and section writers were instructed to emit `[TK]`
rather than invent anything. The assembled draft was then audited back against that table; the
"Editor's notes" section at the end of each file records every reconciliation, every number that
could not be traced, and the contradictions between the drafts and `docs/` that a human still
needs to settle.

## Provenance of the references

54 entries, APA 7th. Two-pass: one agent proposed with search, a second independently re-opened
each source and dropped what it could not confirm. All 39 entries carrying a DOI were then
re-resolved through the Crossref API as a third check. Zero phantom citations, zero uncited
entries. The 15 DOI-less entries are preprints and vendor documentation carrying stable URLs.

## What is deliberately absent

No ground-truth values, no source-paper titles, authors or DOIs, no PDFs. The corpus appears only
as anonymised `CF-P##` identifiers, consistent with the metrics-only policy for `results/`.

## Known gaps a reader should not mistake for results

- The frozen 10-paper test split has never been run. No claim depends on it.
- The 12B and 27B capacity-curve arms have **one sweep each**, so their error bars are unknown —
  visible as missing error bars in Figure 4. Three identical 4B sweeps put UTS MAPE's coefficient
  of variation at 39.3%.
- Two scorer defects (7 and 8) are disclosed but **not yet fixed** in the reported numbers.
- The prompt-engineering ablation is confounded on CF-P11 and CF-P18: `extract_naive.py` defines
  `paper_scope_block()` and never calls it, so the naive arm saw no scope note on the two papers
  holding 67.9% of the between-configuration spread.
